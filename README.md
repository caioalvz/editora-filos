# Filos Editora — Landing Page

Landing page institucional da [Filos Editora](https://filoseditora.com.br), editora brasileira especializada em publicação de livros físicos e digitais com distribuição global.

## Stack

- [Astro 5](https://astro.build) — gerador de site estático
- [GSAP](https://gsap.com) — animação 3D da seção de serviços (lazy-loaded)
- Fontes auto-hospedadas: Spectral + Manrope via `@fontsource`
- Deploy: [Vercel](https://vercel.com)

## Desenvolvimento

```sh
npm install
npm run dev       # http://localhost:4321
npm run build     # build de produção em ./dist/
npm run preview   # preview do build local
```
